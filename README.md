----------Descripció-------------
El projecte és DevTasks, una aplicació web senzilla de gestió de tasques.

L'aplicació permet:
• crear tasques;
• marcar-les com a completades;
• eliminar-les;
• filtrar-les;
• consultar estadístiques;
• conservar les dades mitjançant localStorage.
El projecte està desenvolupat amb:
• HTML
• CSS
• JavaScript
• npm
• Vitest
